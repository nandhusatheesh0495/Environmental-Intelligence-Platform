# Demo Script

## Goal
Run a concise, credible 3–5 minute demonstration of the Environmental Intelligence Platform without implying that it is a production-grade environmental forecasting system.

## Suggested flow

### 1. Open the dashboard
- Launch the frontend and backend.
- Explain that this is a professional monitoring and review console for environmental officers.
- Note that the app supports both operational workflow and synthetic demo data.

### 2. Show the demo mode
- Use the demo toggle on the dashboard.
- Select a demo environment such as River or Landslide.
- Call out that the data is clearly labeled as demo or synthetic and is intended for presentation and QA.

### 3. Show the overview and monitoring map
- Highlight the dashboard summary cards.
- Open the monitoring map and explain the environment filter and detail panel.
- Emphasize that the interface is evidence-first and does not claim disaster probability from visual classification alone.

### 4. Walk through a new analysis
- Navigate to the new analysis flow.
- Select an environment and location.
- Answer a few guided investigation questions.
- Upload before/after imagery.
- Explain the separation between AI confidence and human review.

### 5. Show evidence and review
- Open a generated analysis or review page.
- Highlight evidence and confidence labeling.
- Point out that the review step is human-in-the-loop and that the system requires human confirmation before a report is treated as operationally validated.

### 6. Show citizen reporting
- Submit a citizen observation with environment, location, summary, and image evidence.
- Open the officer review list and explain that the report is separate from AI detections and map features.
- Clarify that this is a safe, manual review path rather than automatic escalation.

## Messaging guidance
Use phrases like:
- "Potential environmental change"
- "AI confidence"
- "Evidence-backed review"
- "Human confirmation required"
- "Synthetic demo dataset"

Avoid phrases like:
- "Disaster probability"
- "Guaranteed conclusion"
- "Real-time hazard detection"
- "Live operational incident data"

## Closing statement
This MVP demonstrates a credible workflow for environmental intelligence: evidence capture, structured review, and human oversight, while remaining transparent about the limits of the current model and the synthetic nature of the demo dataset.
