# Demo dataset

This directory contains a small, deterministic demo dataset for the Environmental Intelligence Platform hackathon MVP.

## Structure

- demo/river/
  - before.png
  - after.png
  - metadata.json
- demo/landslide/
  - before.png
  - after.png
  - metadata.json

## Source and licensing

The demo imagery is intentionally small synthetic examples designed to simulate environmental change for UI and workflow demos. These assets are generated in-repo and are not sourced from external satellite or public-domain imagery.

This keeps the repository self-contained, legal, and reproducible for demonstration use.

## Intended use

These files are for demo-only presentation and reliability testing. They are clearly separated from user-uploaded files and never used as live operational data.
